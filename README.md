# 🚰 Monitoramento de Reservatório de Água

Projeto em Python que simula um painel de console para monitoramento dos níveis de água de um reservatório, emitindo alertas coloridos com base na severidade da situação.

Atividade desenvolvida para a prática de **programação estruturada**, **modularização com funções** e **versionamento via Git/GitHub**.

---

## 📋 Tabela de Níveis e Alertas

| Nível | Situação | Cor no Terminal | Significado Operacional |
| :---: | :--- | :---: | :--- |
| **1** | Muito baixo (crítico) | 🔴 Vermelho | Emergência: risco de esgotamento |
| **2** | Baixo | 🟡 Amarelo | Atenção: capacidade reduzida |
| **3** | Médio | 🟢 Verde | Condição normal de operação |
| **4** | Alto | 🔵 Ciano | Volume elevado |
| **5** | Muito alto (alerta) | 🟦 Azul | Nível máximo: risco de transbordo |

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.10+**
- **Colorama**: estilização e formatação de texto com códigos ANSI no terminal.
- **Git & GitHub**: controle de versão e entrega do projeto.
